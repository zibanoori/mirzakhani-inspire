# Mirzakhani Inspire 🌟

A tribute website dedicated to **Maryam Mirzakhani**, the first woman and first Iranian to win the Fields Medal. This project is built with React, Vite, and Tailwind CSS to showcase her life journey, mathematical contributions, and inspiring legacy.

## 🚀 Features
- **Interactive Timeline:** Key milestones in Maryam's life.
- **Image Gallery:** A responsive grid with a lightbox modal for viewing photos.
- **Inspirational Quotes:** Randomly generated quotes from Maryam Mirzakhani.
- **Birthday Countdown:** A live timer counting down to her next birthday.
- **Dark/Light Mode:** Fully supported theme toggling.
- **Responsive Design:** Optimized for mobile, tablet, and desktop.

## 🛠️ Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Fonts:** Inter & Source Serif 4

## 📂 Project Structure
- `src/components/`: Reusable UI components (Gallery, Quote, Navbar, etc.)
- `src/data/content.js`: Centralized data for text, images, and timeline events.
- `public/`: Static assets like PDFs.
